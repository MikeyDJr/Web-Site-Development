# TechForward

A responsive educational website about computer hardware, web development, and digital safety. Built with HTML, CSS, and JavaScript for a website development course.

## Preview
Open index.html in a browser. No installation or build command is needed. Fonts load from Google Fonts; system fonts work when offline. All illustration artwork is created with CSS.

## Files
- index.html: website structure and educational content
- styles.css: desktop and mobile layouts
- script.js: current year and topic disclosure links

## Accessibility
Includes a skip link, semantic landmarks, logical headings, keyboard-operable native disclosures, visible focus indicators, descriptive links, a text alternative for the informative illustration, decorative content hidden from assistive technology, responsive layouts, and reduced-motion support. No forms collect data. These features are not a claim of certified WCAG compliance.

## Publish to GitHub Pages
1. Create a public GitHub repository named technology-website.
2. Extract the ZIP, then upload index.html, styles.css, script.js, and README.md directly to the repository root. Do not upload the ZIP itself.
3. Commit the files to main.
4. Open Settings > Pages. Under Build and deployment select Deploy from a branch, main, and / (root). Save.
5. Wait for deployment. Copy the actual live URL displayed in Pages and verify that it loads.

Expected project URL format: https://YOUR-USERNAME.github.io/technology-website/
Repository URL format: https://github.com/YOUR-USERNAME/technology-website
Replace YOUR-USERNAME with your actual GitHub username; these are templates, not published URLs.

GitHub documentation: https://docs.github.com/en/pages/quickstart

## Before submitting
Test on desktop and mobile. Tab through all links and disclosure controls. Confirm each topic opens its explanation. Confirm the external resource links load. Submit both the actual repository URL and published Pages URL to Canvas. Compare the final layout with your prior-module wireframe and update it if needed.
