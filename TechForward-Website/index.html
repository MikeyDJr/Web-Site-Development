THE FIVE-MINUTE FOUNDATION

Start small.
Connect the pieces.

Open a question to take a closer look. No technical background required.

What happens when I open an app?

The operating system loads the app’s instructions and data from storage into RAM. The CPU executes instructions, while graphics hardware helps draw what you see. Storage, memory, and processing each have a different job.

How does a website become a page?

Your browser requests files from a server. It interprets HTML for headings, paragraphs, and links; applies CSS for layout and styling; and runs JavaScript for interactions. Responsive CSS helps the layout adapt to different screen sizes.

How can I spot a suspicious message?

Look for unexpected requests, urgent pressure, and sender addresses that do not match the organization. Instead of using the message’s link, open the organization’s known website or app directly. Never share a verification code with someone who contacts you.

What makes a website accessible?

Meaningful headings, descriptive links, readable contrast, text alternatives for informative images, and keyboard controls help more people use a website. Accessibility also means testing with real tools and users rather than relying on appearance alone.
